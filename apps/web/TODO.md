- [x] **На телефоне нечем управлять.** Крестовина `SnakeTouchControls` под полем на тач-устройствах (`pointer: coarse`), на десктопе вместо неё подсказка про клавиши. Кнопки шлют направление по `pointerdown`, чтобы поворот успевал в тик; отправка вынесена из хука в `changeDirection`, клавиатура ходит через неё же.

- [x] **Вид чата.** Лог в стиле Twitch/IRC, а не пузыри: каждая строка — `время  имя  текст`, своё имя цветом акцента. Пузыри слева-справа — метафора диалога на двоих, а в комнате на нескольких человек ведёт имя. Разделители «Today / Yesterday / 5 September 2026» между днями; их вставляет `toChatTimeline` поверх списка newest-first.

- [x] **Первый экран — спиннер на `/auth/*`.** Ожидание refresh переехало из `SessionProvider` в `RequireAuth`: провайдер только запускает refresh и пишет `isInitialized` в стор, ждёт тот гвард, которому сессия нужна. Форма логина рендерится сразу; понадобилась граница Suspense в лэйауте `/auth`, потому что форма читает `useSearchParams` при пререндере.

- [x] **Обрыв связи выглядит как зависание.** В сокет-сторе появился `isReconnecting` — обрыв не по своей воле (`reason !== "io client disconnect"`), сбрасывается при коннекте; ручное отключение при выходе из комнаты его не поднимает, восстановление после `Unauthorized` — поднимает. `ConnectionBanner` в комнате показывает «Connection lost — reconnecting…», если упал любой из трёх сокетов.

- [x] **Разлогин посреди игры.** Сокет отправлял при реконнекте токен, положенный один раз при входе; через два часа он протухал, и любой реконнект — сон ноутбука, моргнувшая сеть, деплой — заканчивался `clearSession()`. Три стора сведены в `createSocketStore(namespace)`: `socket.auth` следует за токеном из стора сессии, на `Unauthorized` делается один refresh через `api.refreshAccessToken()` (дедуплицирован — три сокета ходят за токеном один раз) и переподключение; разлогин только если отвергли и свежий токен. Сессия подставляется в стор через `configureSocketAuth`, чтобы `shared` не зависел от `entities`.
